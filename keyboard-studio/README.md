# NEXTA LAB Custom Keyboard Studio

React, Vite, Three.js and React Three Fiber bilingual keyboard configurator.

Run npm install, npm run dev, and npm run build.

Important: Prices are demonstration values and must be replaced with approved NEXTA LAB selling prices before taking customer requests. The 3D preview is a visual mock-up, not manufacturer CAD. Confirm physical compatibility and stock manually. Telegram currently opens Telegram's share composer; configure a direct NEXTA LAB username when confirmed.
